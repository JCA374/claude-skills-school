# Skills that work together

## One job, five skills

Some jobs are too big for one skill. Your audiobook studio splits narration into five. Speech flow fixes the text for the ear. Narration prep makes the script. Kokoro narrate renders it. Listen check has Whisper listen back. And audiobook assemble packages it.

## voice-text: one door into the pipeline

Voice text is the front door. From any project, one launcher calls each stage in order. It reuses the studio's scripts instead of copying them, so a fix in the studio helps everyone.

## Skills that point to skills

Your project site skill works the same way. It hands the podcast tab to the podcast skill. The podcast skill hands the audio to voice text. And voice text hands the checking to listen check.
