# How a skill learns

## The training loop

A skill gets better when a lesson is written into it. Your studio has a fixed loop. A problem is reported. It becomes a case with a before and an after. You pick the better one. It becomes a rule, and a test keeps it from being undone.

## Measure, then improve

To know that a skill helps, measure it. The skill creator runs the same task with the skill and without it, and you compare. If the skill does not win, change it and run again.
