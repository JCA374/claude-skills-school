# A skill that reviews papers

## The idea

Here is a skill you could build next. It reviews academic papers and reports, the way a careful referee would. It follows the same path every time, and every finding points to a page.

## The review path

The path has five steps. Summarize the claim. Check it against the evidence. Look for luck or leaks in the method. Check the sources. Then give a verdict with a confidence level.

## The folder

The checklists go in a references folder, one per kind of paper. A script pulls out the text and tables. Another script checks that every quote in the review really appears in the paper.

## Make it learn

Then make it learn, like the studio. Keep test papers with known flaws. When a review misses one, that becomes a case and a rule. Run every test paper again after each change.
