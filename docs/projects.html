Learn by building

Projects to learn skills with

Each project teaches one or two ideas from the lessons and is useful on its own. The first version should take one evening; the learning comes from the cases you add afterwards. Start with a ★ one.

Small: one evening

★ start here

Fix your deploy skill

Turn deploy.md into a proper deploy/SKILL.md, fix the path, and add a verification step ("curl the site, expect 200").
Teaches: lesson 3 (where skills live), lesson 5 (done = verified)
★

paper-review

Install the worked example, test it on six papers, add your first two cases.
Teaches: references, gate scripts, the case loop

commit-message

Your style for commit messages and the attribution line. Tiny, but you'll see it fire (or not) dozens of times a week. A perfect description-tuning exercise.
Teaches: lesson 4 (triggers), description optimiser

run-check

"How is the training going?": read stats.csv + events.jsonl of the newest run and answer in five lines, with a sparkline. Uses the same data conventions as ml-project-site.
Teaches: building on an existing convention

Medium: a weekend

★

experiment-design

Before every training run: state the hypothesis, the metric, the baseline, the number of seeds, and what result would change your mind. Writes experiments/NN-plan.md; after the run, failure-analysis-report checks it.
Teaches: skills that hand over to skills (lesson 5); a fixed output form

skill-lint

A script that checks every skill: folder + SKILL.md, required fields, description length, paths that exist (it would have caught all three audit bugs), scripts executable.
Teaches: scripts as gates; it's a skill about skills

lesson-video

Generalise this site's video/build_videos.py: write scenes (narration + visual), voice them with voice-text, render, never loop. Then every project gets explainer films.
Teaches: bundling repeated work into scripts/; composition

report-reviewer for work

A version of paper-review tuned to the reports you actually get: your company's terms, the numbers that matter, the usual mistakes.
Teaches: domain references; project-level skills shared with colleagues

Large: a learning project

★

Skill gym

A repo with 10 of your real past requests as test prompts. For each skill change, skill-creator runs with vs without, and a page shows the scores over time, built with ml-project-site, with a podcast episode when a skill improves.
Teaches: lesson 7 for real; turns skill-writing into an ML-style experiment, which is how you like to work

Research digest

Weekly: fetch new papers on RL / evolution strategies, review each with paper-review, rank them, voice the top three with voice-text, publish as a podcast tab.
Teaches: /schedule, chaining four skills, project-level skills for cloud agents

Teach a skill back

Pick a skill and have Claude generate this kind of school for it: lessons, videos, a podcast, from the skill's own files. It's the same project as this site, but one level more general.
Teaches: everything; a skill that makes courses

How to run any of these

1
Do the task once by hand with Claude, in a normal chat.
2
Say: "Turn what we just did into a skill. Use skill-creator." It interviews you, drafts SKILL.md and test prompts.
3
Use it for real for a week. Every time it's off, add a case and a rule with the why.
4
Measure: with vs without. Tune the description. Ask for a podcast episode about what changed.
